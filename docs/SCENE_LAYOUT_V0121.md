# v0.12.1 餐厅动线重做

本轮根据 Android 真机截图重做空间结构。

## 新动线

入口 → 收银 → 取餐 → 就餐 → 厕所（可选）→ 离店

## 调整

- 收银台从左上移动到入口附近。
- 收银队列改为入口旁横向独立队列，不再穿过餐厅中央。
- 后厨保留左上员工区。
- 三个餐台继续位于右侧，形成连续取餐线。
- 三张双人桌集中到左中部。
- 等座队列移动到左侧边缘。
- 厕所继续位于右下，并保留独立排队点。
- 删除 ZoneStaff / ZoneBuffet / ZoneDining / ZoneRestroom / MainAisle 等半透明调试分区。
- 删除旧低隔断。
- 用 dining_floor / buffet_floor / restroom_floor 三套地面素材自然区分功能区。

## 超长屏

720×1280 仍是核心设计尺寸。

720×1600 等超长屏不再让相机固定在 y=640。
相机根据可视高度下移，让核心餐厅顶部贴近屏幕上方，额外高度显示在场景下方，避免顶部出现大块无意义空白。

## 验收

- 中央不再出现收银/取餐/回桌多线交叉造成的人群团。
- 顾客路线能明显读出入口 → 收银 → 餐台 → 桌位。
- 顶部 HUD 下方不再留大块空白。
- 不依赖半透明色块也能看懂餐厅分区。
- 厨师补菜、服务员清桌、厕所路线仍能完整运行。
