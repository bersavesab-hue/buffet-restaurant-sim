# Buffet Restaurant Sim

Godot 4 自助餐经营模拟项目。当前已经完成第一套垂直切片，并进入手机实机适配阶段。

## 当前版本：v0.10 手机画面校正

### 已完成的核心经营循环

顾客流程：

进店 → 收银排队 → 付款取盘 → 选择餐台 → 取餐排队 → 夹菜 → 端盘找座 → 吃饭 → 再取餐 / 厕所 / 离店。

当前同时具备：

- 69 元门票
- 普通 / 健身 / 大胃王顾客
- 饱食度
- 回本感
- 耐心
- 舒适度
- 温度 / 空调 / 电费
- 厕所需求与排队
- 收银排队
- 餐台排队
- 主食 / 肉类 / 海鲜
- 有限原料库存
- 可见厨师制作和补菜
- 可见服务员收盘和清桌
- 三张双人桌
- 单餐台补菜开关
- 厨房补菜优先级
- 1× / 2× / 3× 时间倍率
- 营业结算和顾客评价

## v0.9 手机适配

项目逻辑基准仍然是：

- 720×1280
- 竖屏
- canvas_items
- expand

新增：

scripts/mobile_layout.gd

它负责：

- Android / iOS 安全区域
- 刘海与状态栏顶部避让
- 底部手势区域避让
- 16:9 / 长屏 / 超长屏 / 宽屏分类
- 超宽逻辑视口时将主要 UI 限制在中央 720 宽区域
- 顶部信息面板和底部三个控制面板动态偏移

场景新增 WorldCamera，将 720×1280 的核心经营区域保持在视口中心。超长屏不会简单把画面纵向拉伸，而是显示更多上下空间。

## 项目原则

- 不为了某张美术重写经营底层。
- 废弃实现直接删除，不长期保留两套入口。
- 第一套母版真机通过后，才批量生产正式素材。
- UI、人物、家具统一遵循 720×1280 与斜俯视规范。


## v0.10 手机画面校正

这一轮没有增加新玩法，专门修手机上的可读性：

- 人物运行显示比例从 0.65 提升到 0.78。
- 吃饭姿态单独调整为 0.80×0.64。
- 餐台取餐点从家具中心侧移到前侧，人物取餐时会正确显示在餐台前方。
- 厨师补菜点保留在餐台后方。
- 餐台排队间距从 46 增加到 54。
- 双人桌上下两个座位继续分别形成“人物在桌后 / 人物在桌前”的斜俯视遮挡。
- 底部所有按钮最小触控高度统一为 52。
- 底部三排操作区整体高度缩小，给餐厅场景腾出更多空间。
- 顶部信息面板改为根据内容自动计算高度，并限制在 220～258。
- v0.10 最新 main 已通过布局规则测试和 Godot 主场景启动测试。
