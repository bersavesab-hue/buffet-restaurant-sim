# Buffet Restaurant Sim

Godot 4 自助餐经营模拟项目。当前阶段严格使用灰盒占位资产，先验证顾客、餐台、座位和经营行为，再进入正式美术。

## 当前版本：v0.2 灰盒基础循环

已完成：

- 竖屏 540×960 基准画布
- Godot 4 主场景
- NavigationRegion2D + NavigationAgent2D 基础寻路
- 顾客状态机：进店 → 收银 → 取餐 → 回座 → 吃饭 → 再取餐/离店
- 餐台库存与单份饱食度
- 两个可占用/释放座位
- 顾客最小饱食度系统
- 实时调试信息：顾客状态、饱食度、库存、座位占用
- R 键重开测试场景

## 当前故意不做

- 正式人物和家具美术
- 菜品成本/顾客认知价值/回本感
- 多顾客队列
- 收银排队
- 温度、空调、厕所
- 员工 AI
- 自由装修与扩建
- 正式 UI

这些系统会在基础循环验证后逐层加入，避免把未经验证的玩法写死在底层。

## 下一阶段：v0.3

目标是把单顾客原型推进到小规模餐厅模拟：

1. 多顾客生成与排队
2. 多餐台选择
3. 顾客胃容量与取餐份量差异
4. 回本感（顾客主观价值）
5. 真实收入与食材成本统计
6. 一次完整营业日的最小结算

## 项目原则

- 底层对象统一接口，不为每道菜/每个餐台复制脚本。
- 原型阶段允许重构；垂直切片通过后再冻结核心接口。
- UI 只控制模拟世界，不用 UI 替代实际经营场景。
- 正式素材批量生产前先锁定视角、比例、占格和动画母版。
