# Buffet Restaurant Sim

Godot 4 自助餐经营模拟项目。当前阶段严格使用灰盒占位资产，先验证顾客、餐台、座位、排队、饱食与经营经济，再进入正式美术。

## 当前版本：v0.3 小型真实营业

### 已完成

- 逻辑基准统一为 720×1280（9:16）
- 使用 canvas_items + expand 适配不同竖屏手机比例
- Godot 4 主场景与可复用顾客场景
- 多顾客动态生成
- 收银排队 + 单人收银服务
- 3 类餐台：主食 / 烤肉 / 海鲜
- 餐台使用浮点份量单位，允许不同顾客每次夹取不同分量
- 3 种顾客原型：普通、健身、大胃王
- 不同胃容量、单次取餐量、菜品偏好、追求回本程度
- 饱食度系统
- 顾客回本感：按顾客主观价值 / 门票价格计算
- 菜品实际成本与顾客主观价值分离
- 门票收入、食材成本、当前毛利实时统计
- 75 秒最小营业日
- 营业结束后显示顾客数、平均回本感、毛利
- 6 个可占用/释放座位
- R 键重新开始灰盒测试

## 当前核心验证目标

1. 顾客是否会因为类型不同而表现出不同取餐行为。
2. 主食、肉类、海鲜能否形成真实的成本/饱腹/回本感取舍。
3. 大胃王是否会明显拉高成本，但又不是必然亏损。
4. 收银与座位容量是否开始形成高峰压力。
5. 69 元门票下，玩家是否有调整菜单结构的动力。

## 下一阶段 v0.4

- 餐台补菜与厨房产能
- 无座时等待，而不是直接离店
- 顾客耐心值
- 温度 / 空调 / 舒适度
- 厕所需求与厕所排队
- 更完整的一日结算和顾客评价原因
- 时间倍率 1× / 2× / 3×

## 项目原则

- 核心模拟先于正式 UI 和美术。
- 同类对象使用统一接口，不为每道菜或每个餐台复制脚本。
- 原型阶段允许重构；垂直切片通过后再冻结核心接口。
- UI 只负责观察和控制模拟世界，不用 UI 替代实际经营场景。
- 正式素材批量生产前先锁定视角、比例、占格和动画母版。
