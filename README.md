# Buffet Restaurant Sim

Godot 4 自助餐经营模拟项目。当前已经完成第一套垂直切片，并进入手机实机适配阶段。

## 当前版本：v0.12.2 Stage 0 网格布局迁移

### 已完成的核心经营循环

顾客流程：

进店 → 收银排队 → 付款取盘 → 选择餐台 → 取餐排队 → 夹菜 → 端盘找座 → 吃饭 → 再取餐 / 厕所 / 离店。

当前同时具备：

- 69 元门票
- 普通 / 健身 / 大胃王顾客
- 饱食度
- 回本感
- 耐心
- 舒适度
- 温度 / 空调 / 电费
- 厕所需求与排队
- 收银排队
- 餐台排队
- 主食 / 肉类 / 海鲜
- 有限原料库存
- 可见厨师制作和补菜
- 可见服务员收盘和清桌
- 三张双人桌
- 单餐台补菜开关
- 厨房补菜优先级
- 1× / 2× / 3× 时间倍率
- 营业结算和顾客评价

## v0.9 手机适配

项目逻辑基准仍然是：

- 720×1280
- 竖屏
- canvas_items
- expand

新增：

scripts/mobile_layout.gd

它负责：

- Android / iOS 安全区域
- 刘海与状态栏顶部避让
- 底部手势区域避让
- 16:9 / 长屏 / 超长屏 / 宽屏分类
- 超宽逻辑视口时将主要 UI 限制在中央 720 宽区域
- 顶部信息面板和底部三个控制面板动态偏移

场景新增 WorldCamera，将 720×1280 的核心经营区域保持在视口中心。超长屏不会简单把画面纵向拉伸，而是显示更多上下空间。

## v0.12.2 Stage 0 网格布局迁移

当前小店的9件核心家具已经不再依赖手写世界坐标：

- 3张双人桌
- 3个餐台
- 收银台
- 后厨工作台
- 厕所

它们现在全部使用：

FurnitureDefinition → grid_position → RestaurantGrid → world position

Stage 0 当前布局：

- 厨房：13,14
- 主食台：18,10
- 烤肉台：20,12
- 海鲜台：22,14
- A桌：15,17
- B桌：16,20
- C桌：18,22
- 收银台：17,24
- 厕所：25,22

网格原点调整为 (360,160)，保持64×32菱形格不变，让开局餐厅在竖屏上有更合适的纵深。

FurniturePlacementManager 启动时自动登记所有 use_grid_placement 家具；启动自检要求必须得到：

- 9件登记家具
- 57个占用格

否则主场景验证失败。

下一步开始真正的装修交互原型：进入装修模式、网格显示、家具选中、半透明预览、绿色/红色可放判定、旋转和确认放置。
