# Buffet Restaurant Sim

Godot 4 自助餐经营模拟项目。当前已经完成第一套垂直切片，并进入手机实机适配阶段。

## 当前版本：v0.14.1 玩家控制链路清理

- 删除隐藏的旧 UI、SupplyControls、PriorityControls、Controls 节点与转接按钮。
- 补菜、厨房、空调、倍速、装修由 GameHUD 直接调用唯一的经营操作。
- 手机布局只负责安全区与镜头；运行诊断直接显示在正式设置抽屉。
- 自动测试逐个触发玩家按钮，验证经营数据随操作变化。

### v0.14.0 跨天经营与存档修复

- 营业时间结束后先等待店内顾客离开，再进行日结。
- 经营抽屉在结算后提供“开始下一天”；资金、天数、已移动和已移除的家具自动保存。
- 重开游戏从下一营业日继续；新的一天重新采购食材并重新计算当日收支。
- 装修至少保留一个餐台和一张餐桌，启动诊断按照实际家具数量验算占格。
- 调整收银服务点和桌边座位，修复顾客被家具避障挡住后无法付款、就餐和结算的问题。
- Android 调试包使用固定的开发签名，后续调试版本可以覆盖安装。

存档保留经营天数、资金和现有家具布局。当天尚未结算的客流、原料余量和营业额在退出游戏后重新开始该营业日。v0.13.1 使用不同的临时调试签名，首次安装 v0.14.0 可能需要先卸载旧包；卸载会清除旧包本地数据。

### 已完成的核心经营循环

顾客流程：

进店 → 收银排队 → 付款取盘 → 选择餐台 → 取餐排队 → 夹菜 → 端盘找座 → 吃饭 → 再取餐 / 厕所 / 离店。

当前同时具备：

- 69 元门票
- 普通 / 健身 / 大胃王顾客
- 饱食度
- 回本感
- 耐心
- 舒适度
- 温度 / 空调 / 电费
- 厕所需求与排队
- 收银排队
- 餐台排队
- 主食 / 肉类 / 海鲜
- 有限原料库存
- 可见厨师制作和补菜
- 可见服务员收盘和清桌
- 三张双人桌
- 单餐台补菜开关
- 厨房补菜优先级
- 1× / 2× / 3× 时间倍率
- 营业结算和顾客评价

## v0.12.3 装修模式原型

当前已经可以从游戏底部点击“装修”进入实际装修模式。

装修模式行为：

- 使用 SceneTree.pause 暂停营业、顾客和员工。
- 显示 Stage 0 菱形建造网格。
- 开启餐厅摄像机拖动/缩放。
- 点击已有家具即可选中。
- 拖动选中家具时只移动占格预览，不立即修改真实家具。
- 绿色格表示当前位置可以放置。
- 红色格表示未解锁区域或与其他家具冲突。
- 点击确认后才真正更新 FurniturePlacementManager 占格。
- 点击取消不会改变原家具。
- 支持占格旋转逻辑。
- 空闲家具才能移动；正在被顾客/员工使用时会明确阻止。
- 当前“移除”只允许安全移除桌子/餐台；收银台、厨房、厕所属于开局必需基础设施，只允许移动。
- 移除暂时不返还资金，等正式资金/装修商店系统接入后再改成出售退款。

当前版本仍然只操作“已有家具”。

下一步：

1. 建立装修家具目录。
2. 从目录新建双人桌/餐台。
3. 半透明新家具跟随手指。
4. 放置时扣除资金。
5. 已放家具出售返还部分资金。
6. 地板/墙面迁移到装修层。
7. 最后动态重建 NavigationRegion，而不是继续依赖当前固定导航区域。
